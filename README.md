# RISC-V Processor with Integrated Memory Subsystem and Systolic Array Accelerator

A Verilog implementation of a **32-bit RV32I five-stage pipelined RISC-V processor** integrated with a cache-based memory subsystem, registered AXI-style interconnect, hardware prefetcher, and a memory-mapped 4×4 systolic array accelerator for matrix multiplication.

---

# Project Motivation

Modern embedded processors increasingly rely on specialized hardware accelerators and efficient memory hierarchies to improve performance while maintaining low hardware complexity.

This project explores that concept by extending a five-stage RV32I processor into a complete hardware platform. Rather than implementing only a processor core, the design integrates cache management, branch prediction, hardware prefetching, an AXI-style interconnect, memory control logic, and a systolic array accelerator into a unified RTL implementation.

The project demonstrates how these hardware components cooperate to execute programs while accelerating matrix multiplication through a dedicated hardware accelerator.

---

# Project Overview

The processor implements the **RV32I Instruction Set Architecture** using a classic five-stage pipeline consisting of:

- Instruction Fetch (IF)
- Instruction Decode (ID)
- Execute (EX)
- Memory Access (MEM)
- Write Back (WB)

Pipeline hazards are handled using forwarding logic, hazard detection, and branch prediction.

Memory requests generated by the processor are serviced through an integrated memory subsystem consisting of:

- Two-way set associative cache
- LRU replacement policy
- Cache controller
- Hardware prefetcher
- Registered AXI-style interconnect
- Memory controller

The hardware prefetcher is integrated within the cache controller and issues speculative memory requests based on observed access patterns.

To accelerate matrix multiplication, the processor communicates with a memory-mapped 4×4 systolic array accelerator. Matrix data is written into dedicated SRAM blocks, computation is initiated through control registers, and results are read back once the accelerator signals completion.

# Processor Pipeline

The processor follows the standard five-stage RISC-V pipeline.

```
Instruction Fetch
        │
        ▼
Instruction Decode
        │
        ▼
Execute
        │
        ▼
Memory Access
        │
        ▼
Write Back
```

Pipeline hazards are minimized through:

- Hazard Detection Unit
- Forwarding Unit
- Branch Predictor

---

# Memory Subsystem

The processor communicates with memory through a cache-based hierarchy.

```
Processor
     │
     ▼
Cache Controller
     │
     ├── Hardware Prefetcher
     │
     ▼
AXI-style Interconnect
     │
     ▼
Memory Controller
     │
     ▼
Data Memory
```

The interconnect is implemented as a **registered pass-through interconnect**, introducing a one-cycle pipeline stage between major memory components while avoiding combinational feedback paths.

---

# Systolic Array Accelerator

The processor controls the accelerator through a memory-mapped interface.

```
Processor

      │

      ▼

Load Matrix A

      │

      ▼

Load Matrix B

      │

      ▼

Write START Register

      │

      ▼

Accelerator Controller

      │

      ▼

4×4 Systolic Array

      │

      ▼

Matrix Multiplication

      │

      ▼

DONE Signal

      │

      ▼

Read Result Matrix
```

The accelerator performs parallel matrix multiplication using a 4×4 array of Processing Elements and dedicated Matrix SRAM blocks.
